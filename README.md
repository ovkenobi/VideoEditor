# Видеоредактор FFmpeg

Учебное приложение для простого редактирования видео на Windows.
Написано на C++17 с использованием Qt 6 Widgets, система сборки — CMake.
Все операции с видео выполняются внешними программами `ffmpeg.exe` и `ffprobe.exe`.

## Возможности

1. **Склейка двух видеофайлов**
   - при совпадении кодека, разрешения, пиксельного формата и параметров аудио — быстрое склеивание без перекодирования (`concat` + `-c copy`);
   - разная частота кадров не является причиной перекодирования: такие файлы тоже склеиваются копированием;
   - при прочих различиях — перекодирование с приведением разрешения, fps и аудио к параметрам первого файла;
   - поддержка файлов без аудиодорожки (для отсутствующей дорожки добавляется тишина).

2. **Извлечение всех кадров**
   - в PNG или JPG;
   - с настраиваемым префиксом и качеством JPEG;
   - с сохранением всех кадров, включая видео с переменной частотой (`-fps_mode passthrough`).

3. **Создание видео из набора кадров**
   - автоматическое определение шаблона имён, количества и размера кадров;
   - обязательное указание конечной длительности видео;
   - частота кадров рассчитывается как `количество кадров / длительность`;
   - итоговый файл ограничивается заданной длительностью (`-t`).

4. **Наложение изображения на извлечённые кадры**
   - выбор папки с кадрами и изображения наложения (PNG/JPG/BMP);
   - координаты `X`, `Y`;
   - номер первого кадра и количество кадров;
   - предпросмотр результата с масштабированием: «Вписать», 100 %, увеличение до 800 %, прокрутка и `Ctrl`+колесо мыши;
   - исходные кадры не изменяются, результат сохраняется в отдельную папку;
   - обработка выполняется фильтром FFmpeg `overlay` с `enable='between(n,…)'`.

Все операции выполняются асинхронно: интерфейс не блокируется, отображается прогресс,
есть кнопка отмены и журнал с точной командой FFmpeg.

## Требования

- Windows 10/11 x64;
- Qt 6 (проверено на Qt 6.10.1, MinGW);
- CMake 3.21+;
- Ninja (рекомендуется);
- MinGW GCC (проверено на GCC 15.2 из MSYS2);
- `ffmpeg.exe` и `ffprobe.exe` в корне проекта (или в `PATH`).

## Сборка

Из MSYS2 MinGW-окружения или обычного PowerShell, где доступны CMake и MinGW:

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release `
      -DCMAKE_PREFIX_PATH=C:/msys64/mingw64
cmake --build build --parallel
```

После сборки `ffmpeg.exe` и `ffprobe.exe` автоматически копируются в папку `build`.
Запуск:

```powershell
.\build\VideoEditor.exe
```

Если приложение запускается не из MSYS2-окружения, Qt DLL могут быть не найдены.
Для переноса на другой компьютер используйте скрипт развёртывания:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\deploy.ps1
```

Он создаст папку `dist` с `VideoEditor.exe`, `ffmpeg.exe`, `ffprobe.exe` и всеми
необходимыми библиотеками Qt/MinGW.

## Как пользоваться

### Склейка видео

1. Выберите два видеофайла. Под каждым отобразится длительность, разрешение, fps и аудио.
2. Укажите выходной файл (по умолчанию — MP4).
3. Режим «Авто» сам выберет быстрое копирование или перекодирование.
4. Нажмите «Склеить видео».

### Извлечение кадров

1. Выберите видеофайл.
2. Укажите папку, префикс и формат PNG/JPG.
3. Нажмите «Извлечь все кадры».
4. Кадры получат имена вида `frame_000001.png`.

### Кадры → видео

1. Выберите папку с кадрами. Программа найдёт непрерывную последовательность.
2. Укажите конечную длительность в секундах.
3. Проверьте рассчитанную частоту кадров.
4. Укажите выходной файл и нажмите «Создать видео из кадров».

Например, 100 кадров и длительность 10 секунд дают 10 кадров/с.

### Наложение изображения

1. Выберите папку с извлечёнными кадрами.
2. Выберите изображение наложения.
3. Задайте координаты `X`, `Y`, номер первого кадра и количество кадров.
4. Проверьте предпросмотр. Масштаб меняется кнопками `−`/`+`, ползунком, полем процентов, кнопками «Вписать» и «100%», а также колесом мыши с зажатым `Ctrl`. При увеличении превью прокручивается.
5. Выберите отдельную папку результата и нажмите «Наложить изображение».

## Используемые команды FFmpeg (кратко)

- Склейка без перекодирования: `-f concat -safe 0 -i list.txt -c copy`.
- Склейка с перекодированием: `scale`, `pad`, `fps`, `concat`, `libx264`, `aac`.
- Извлечение кадров: `-fps_mode passthrough` + шаблон `frame_%06d.png`.
- Кадры → видео: `-framerate <fps> -start_number <n> -i pattern -t <duration>`.
- Наложение: `overlay=x:y:enable='between(n,start,end)'`.

## Тестовые данные

Скрипт создаёт два тестовых ролика с разными параметрами:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\make_test_clips.ps1
```

## Примечания

- Используемая сборка FFmpeg распространяется по лицензии GPL; при передаче
  программы вместе с `ffmpeg.exe` необходимо соблюдать условия её лицензии.
- Для очень длинных видео извлечение всех кадров может занять много места на диске.
- Наложение выполняется с промежуточным сохранением изображений, поэтому для больших
  наборов кадров требуется свободное место.
- Формат MP4 с `yuv420p` требует чётных размеров кадра; программа автоматически
  приводит размеры к чётным.
